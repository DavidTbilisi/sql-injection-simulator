# SQL Injection Simulator

A browser-only, synthetic SQL injection teaching simulator. It demonstrates error-based, UNION-based, boolean blind, time-based blind, stacked-query, second-order, and out-of-band concepts without connecting to a server or database.

## Safety

- No network requests
- No real database
- No stored user data
- Fake tables, responses, callbacks, and timing signals

## GitHub Pages

The site is deployed automatically from the repository root by the included GitHub Actions workflow.
